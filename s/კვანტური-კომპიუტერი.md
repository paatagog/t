## შესავალი

ეს აპლიკაცია არის 8-კუბიტიანი კვანტური კომპიუტერის ინტერაქტიული სიმულატორი, რომელიც ბრაუზერში მუშაობს. მისი მიზანია კვანტური გამოთვლების ფუნდამენტური კონცეფციების ვიზუალური და ინტუიციური წარმოდგენა. სიმულატორი საშუალებას იძლევა, მომხმარებელმა კვანტური გეითები გამოიყენოს კუბიტებზე და რეალურ დროში დააკვირდეს, თუ როგორ იცვლება კვანტური მდგომარეობები.

სიმულატორი **არ არის** სრულმასშტაბური კვანტური ემულატორი — იგი ცალკეულ კუბიტებს მოდელირებს დამოუკიდებლად (გარდა CNOT ოპერაციისა), რაც პედაგოგიურ მიზნებს ემსახურება.

## ფიზიკური საფუძვლები

### 2.1 კუბიტი — კვანტური ბიტი

კლასიკური კომპიუტერი ინფორმაციას ინახავს **ბიტებში**, რომელთაგან თითოეული იღებს მნიშვნელობას 0 ან 1. კვანტურ კომპიუტერში ინფორმაციის ერთეული არის **კუბიტი** (qubit — quantum bit).

კუბიტის ფუნდამენტური განსხვავება ბიტისგან ის არის, რომ კუბიტი შეიძლება იმყოფებოდეს |0⟩ და |1⟩ მდგომარეობების **სუპერპოზიციაში** — ანუ ერთდროულად ორივე მდგომარეობაში, განსაზღვრული ალბათობებით.

მათემატიკურად, კუბიტის მდგომარეობა იწერება:

```
|ψ⟩ = α|0⟩ + β|1⟩
```

სადაც α და β არის კომპლექსური რიცხვები (ამპლიტუდები), რომლებიც აკმაყოფილებენ ნორმირების პირობას:

```
|α|² + |β|² = 1
```

|α|² არის ალბათობა, რომ გაზომვისას მივიღებთ |0⟩, ხოლო |β|² — ალბათობა |1⟩-ის მისაღებად.

### 2.2 სუპერპოზიცია

სუპერპოზიცია კვანტური მექანიკის ერთ-ერთი ფუნდამენტური პრინციპია. კლასიკური ფიზიკისგან განსხვავებით, კვანტურ სისტემას შეუძლია ერთდროულად იმყოფებოდეს რამდენიმე მდგომარეობაში.

ანალოგია: წარმოიდგინეთ მონეტა, რომელიც ბრუნავს ჰაერში — სანამ მაგიდას არ დაეცემა (გაზომვა), ის არც „ბორჯღალოა" და არც „ციფრი", არამედ ორივეს ნარევია. გაზომვის მომენტში კი აუცილებლად ერთ-ერთი მხარეზე ეცემა.

n კუბიტის სისტემას შეუძლია ერთდროულად 2ⁿ მდგომარეობაში იყოს. ჩვენი 8-კუბიტიანი სიმულატორისთვის ეს 2⁸ = **256 მდგომარეობაა** ერთდროულად.

### 2.3 ბლოხის სფერო

ბლოხის სფერო არის ერთი კუბიტის მდგომარეობის გეომეტრიული წარმოდგენის სტანდარტული ხერხი. ეს არის ერთეულოვანი რადიუსის სფერო, რომლის:

- **ჩრდილოეთი პოლუსი** (ზედა) = |0⟩ მდგომარეობა
- **სამხრეთი პოლუსი** (ქვედა) = |1⟩ მდგომარეობა
- **ეკვატორი** = თანაბარი სუპერპოზიცია (50%/50%)

კუბიტის ნებისმიერი წმინდა მდგომარეობა შეიძლება გამოისახოს სფეროს ზედაპირზე ერთი წერტილით, რომელიც განისაზღვრება ორი კუთხით:

```
|ψ⟩ = cos(θ/2)|0⟩ + e^(iφ) · sin(θ/2)|1⟩
```

- **θ (თეტა)** — პოლარული კუთხე (0°-დან 180°-მდე): განსაზღვრავს |0⟩ და |1⟩ ალბათობების თანაფარდობას
  - θ = 0° → სუფთა |0⟩
  - θ = 90° → თანაბარი სუპერპოზიცია
  - θ = 180° → სუფთა |1⟩
- **φ (ფი)** — აზიმუტალური კუთხე (0°-დან 360°-მდე): განსაზღვრავს ფაზას ამპლიტუდებს შორის

ფაზას (φ) უშუალო გავლენა არ აქვს ალბათობებზე, მაგრამ კრიტიკულ როლს ასრულებს კვანტურ ინტერფერენციაში — ეს არის ის, რაც კვანტურ გამოთვლებს უნიკალურ სიმძლავრეს ანიჭებს.

სიმულატორში ბლოხის სფერო **ნელა ბრუნავს**, რაც სხვადასხვა კუთხიდან ხედვას უზრუნველყოფს. ოქროსფერი ვექტორი სფეროს ცენტრიდან ზედაპირის წერტილამდე მიუთითებს არჩეული კუბიტის მიმდინარე მდგომარეობას.

### 2.4 კვანტური გეითები

კლასიკურ კომპიუტერში ლოგიკური ოპერაციები სრულდება გეითებით (AND, OR, NOT). კვანტურ კომპიუტერში ანალოგიურად არსებობს **კვანტური გეითები** — უნიტარული გარდაქმნები, რომლებიც კუბიტის მდგომარეობას ცვლიან.

#### ჰადამარის გეითი (H)

ჰადამარის გეითი კვანტური გამოთვლების ყველაზე ფუნდამენტური ოპერაციაა. ის ქმნის **თანაბარ სუპერპოზიციას**:

```
H|0⟩ = (|0⟩ + |1⟩) / √2
H|1⟩ = (|0⟩ − |1⟩) / √2
```

მატრიცული ჩანაწერი:

```
H = (1/√2) · [ 1   1 ]
              [ 1  -1 ]
```

ბლოხის სფეროზე: H გეითი ახდენს მდგომარეობის ბრუნვას X+Z ღერძის გარშემო 180°-ით. |0⟩-დან იგი კუბიტს ეკვატორზე გადაიყვანს (+X მიმართულებით), ხოლო |1⟩-დან — ასევე ეკვატორზე, მაგრამ საპირისპირო მხარეს (-X მიმართულებით).

H გეითის ორჯერ გამოყენება აბრუნებს კუბიტს საწყის მდგომარეობაში: H·H = I (ერთეულოვანი მატრიცა).

#### პაულის X გეითი (NOT)

X გეითი კვანტური NOT ოპერაციაა — ის ცვლის |0⟩ და |1⟩ მდგომარეობებს:

```
X|0⟩ = |1⟩
X|1⟩ = |0⟩
```

მატრიცული ჩანაწერი:

```
X = [ 0  1 ]
    [ 1  0 ]
```

ბლოხის სფეროზე: X გეითი ახდენს ბრუნვას X ღერძის გარშემო 180°-ით. ეს ნიშნავს, რომ ჩრდილოეთ პოლუსი სამხრეთში გადადის და პირიქით.

სუპერპოზიციის მდგომარეობაზე X გეითი ამპლიტუდებს ცვლის: α|0⟩ + β|1⟩ → β|0⟩ + α|1⟩.

#### CNOT გეითი (Controlled-NOT)

CNOT არის ორ-კუბიტიანი გეითი — ეს არის კვანტური გადაჯაჭვულობის შესაქმნელად გამოყენებული მთავარი ინსტრუმენტი.

CNOT-ს ჰყავს ორი მონაწილე:
- **კონტროლის კუბიტი** (control): განსაზღვრავს, მოხდეს თუ არა ოპერაცია
- **სამიზნე კუბიტი** (target): მასზე სრულდება ოპერაცია

ლოგიკა: თუ კონტროლის კუბიტი არის |1⟩, მაშინ სამიზნე კუბიტს ეკეთება NOT (X). თუ კონტროლი არის |0⟩, არაფერი ხდება.

```
CNOT|00⟩ = |00⟩
CNOT|01⟩ = |01⟩
CNOT|10⟩ = |11⟩   ← კონტროლი=1, ამიტომ სამიზნე შეიცვალა
CNOT|11⟩ = |10⟩   ← კონტროლი=1, ამიტომ სამიზნე შეიცვალა
```

კრიტიკული თვისება: თუ CNOT-ს კონტროლ კუბიტზე სუპერპოზიციაა (H გეითის შედეგად), CNOT ქმნის **ენთენგლმენტს** — ორი კუბიტის მდგომარეობები ურთიერთდაკავშირებული ხდება.

სიმულატორში CNOT ყოველთვის მოქმედებს არჩეულ კუბიტზე (როგორც კონტროლი) და მის მომდევნო კუბიტზე (როგორც სამიზნე). გადაჯაჭვულობის რუკაზე ეს კავშირი მაგენტა ხაზით ჩანს.

### 2.5 კვანტური გადაჯაჭვულობა (ენთენგლმენტი)

კვანტური გადაჯაჭვულობა — რომელსაც აინშტაინმა „სასოწარკვეთილი მოქმედება მანძილზე" (spooky action at a distance) უწოდა — კვანტური მექანიკის უჩვეულო მოვლენაა.

როცა ორი კუბიტი გადაჯაჭვულია, ერთის გაზომვა **მყისიერად** განსაზღვრავს მეორის მდგომარეობასაც, მიუხედავად მათ შორის მანძილისა.

ბელის მდგომარეობის მაგალითი — ყველაზე მარტივი გადაჯაჭვული წყვილი:

```
|Φ+⟩ = (|00⟩ + |11⟩) / √2
```

ეს ნიშნავს: სისტემა 50%-ით არის |00⟩ (ორივე 0) და 50%-ით |11⟩ (ორივე 1). ორივე კუბიტი ცალ-ცალკე სრულ სუპერპოზიციაშია, მაგრამ გაზომვის შედეგები ყოველთვის კორელირებულია.

ბელის მდგომარეობის მისაღებად სიმულატორში: ჯერ გამოიყენეთ H გეითი Q0-ზე (შეიქმნება სუპერპოზიცია), შემდეგ CNOT (Q0 → Q1). შედეგად Q0 და Q1 გადაჯაჭვული გახდება.

გადაჯაჭვულობა არის კვანტური გამოთვლების სიმძლავრის ძირითადი წყარო. ის საშუალებას იძლევა, n კუბიტის სისტემამ ერთდროულად 2ⁿ გამოთვლითი ბილიკი დაამუშაოს — ეს არის ე.წ. **კვანტური პარალელიზმი**.

### 2.6 გაზომვა და ალბათობა

კვანტური გაზომვა ფუნდამენტურად განსხვავდება კლასიკური გაზომვისგან — ის **არღვევს** სუპერპოზიციას.

გაზომვის ბორნის წესი: თუ კუბიტი მდგომარეობაშია |ψ⟩ = α|0⟩ + β|1⟩, გაზომვისას:
- ალბათობა(0) = |α|²
- ალბათობა(1) = |β|²

გაზომვის შემდეგ კუბიტი „ჩამოინგრევა" (collapse) შესაბამის ბაზისურ მდგომარეობაში და სუპერპოზიცია იკარგება.

სიმულატორში ალბათობის განაწილების პანელი აჩვენებს 4 კუბიტის (Q0–Q3) კომბინირებულ ალბათობებს 16 ბაზისურ მდგომარეობაში (|0000⟩-დან |1111⟩-მდე), საიდანაც 8 ყველაზე სავარაუდო ნაჩვენებია.

### 2.7 კვანტური წრედი

კვანტური წრედი არის კვანტური ალგორითმის გრაფიკული ჩანაწერი. ის იკითხება მარცხნიდან მარჯვნივ (დროის მიმართულებით):

- **ჰორიზონტალური ხაზები** — კუბიტების „მავთულები" (q0, q1, ...)
- **კვადრატული ბლოკები** — ერთ-კუბიტიანი გეითები (H, X)
- **წერტილი + ⊕ სიმბოლო** — CNOT (წერტილი = კონტროლი, ⊕ = სამიზნე)
- **მრიცხველის სიმბოლო** (ბოლოში) — გაზომვა

სიმულატორი აჩვენებს ბოლო N ოპერაციას, რამდენიც ეკრანზე ეტევა.

### 2.8 ფიდელობა

ფიდელობა (fidelity) ზომავს, რამდენად ახლოსაა რეალური კვანტური მდგომარეობა სასურველ იდეალურ მდგომარეობასთან. მათემატიკურად:

```
F(ρ, σ) = (Tr√(√ρ · σ · √ρ))²
```

რეალურ კვანტურ კომპიუტერებში ფიდელობა მცირდება ყოველი ოპერაციის შემდეგ, რადგან ხმაური (noise) და დეკოჰერენცია (decoherence) აზიანებს კვანტურ მდგომარეობას. სიმულატორი მოდელირებს ამ ეფექტს: ყოველი გეითის შემდეგ ფიდელობა 0.7%-ით მცირდება (მინიმუმ 85%).

## ინტერფეისის აღწერა

### 3.1 ბლოხის სფერო

ინტერფეისის ზედა მარცხენა პანელი. აჩვენებს არჩეული კუბიტის მდგომარეობას 3D სფეროზე:

- **ოქროსფერი ვექტორი** — კუბიტის მიმდინარე მდგომარეობა
- **ზედა პოლუსი** — |0⟩
- **ქვედა პოლუსი** — |1⟩
- **ეკვატორი** — სუპერპოზიცია
- **θ და φ მნიშვნელობები** — ნაჩვენებია ქვედა მარცხენა კუთხეში

სფეროს ქვეშ Q0–Q3 ღილაკებით ხდება კუბიტის არჩევა ვიზუალიზაციისთვის.

### 3.2 კუბიტ რეგისტრი

ზედა მარჯვენა პანელი. 8 კუბიტი ნაჩვენებია 4×2 ბადეში. თითოეულ უჯრაში:

- **Q0–Q7** — კუბიტის ნომერი
- **მდგომარეობა** — |0⟩, |1⟩ ან |ψ⟩ (სუპერპოზიცია)
- **ალბათობები** — P(0)% | P(1)%
- **ფაზის რგოლი** — ისრის კუთხე აჩვენებს φ ფაზას

გადაჯაჭვული კუბიტები **მაგენტა** ჩარჩოთი გამოირჩევა. კუბიტზე დაჭერით ის ირჩევა ბლოხის სფეროსთვის და გეითი ოპერაციებისთვის.

ღილაკები რეგისტრის ქვემოთ:
- **H Gate** — ჰადამარის გეითი (სუპერპოზიციის შექმნა)
- **X Gate** — NOT ოპერაცია
- **CNOT** — კონტროლირებადი NOT (გადაჯაჭვულობის შექმნა)
- **Reset** — ყველა კუბიტის განულება

### 3.3 კვანტური წრედი

სრული სიგანის პანელი ორი ზედა პანელის ქვემოთ. აჩვენებს გამოყენებული ოპერაციების თანმიმდევრობას წრედის დიაგრამის სახით. 5 კუბიტის მავთული ნაჩვენებია (q0–q4). წრედის ბოლოში გაზომვის სიმბოლოებია.

### 3.4 ალბათობის განაწილება

აჩვენებს 4-კუბიტიანი ქვესისტემის (Q0–Q3) ბაზისურ მდგომარეობათა ალბათობებს ჰორიზონტალური ზოლების სახით. |0000⟩-დან |1111⟩-მდე 16 მდგომარეობიდან 8 ყველაზე სავარაუდო ნაჩვენებია. ზოლის სიგრძე ალბათობის პროპორციულია, რიცხვითი მნიშვნელობა მარჯვნივ წერია.

### 3.5 გადაჯაჭვულობის რუკა

8 კუბიტი წრიულად განლაგებულია. გადაჯაჭვული წყვილები დაკავშირებულია **გრადიენტული ხაზით** (მაგენტადან ცისფერამდე). ხაზზე მოძრავი ანიმირებული ნაწილაკი კავშირის ვიზუალურ ილუსტრაციას ქმნის. არჩეული კუბიტი გამორჩეულია უფრო დიდი წრით.
